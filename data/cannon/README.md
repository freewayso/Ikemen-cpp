# Fire cannon sprite pack

Pixel-art frames for the KFM rage skill (not a third-party download).

| Prefix | Frames | Use |
|--------|--------|-----|
| `shot_00` … `shot_07` | flying shell + flame trail |
| `boom_00` … `boom_05` | impact burst |
| `muzzle_00` … `muzzle_03` | palm flash when firing |

Regenerate:

```
py -3 cpp/tools/gen_cannon.py
```
